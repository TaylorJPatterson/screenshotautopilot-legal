# smartrenamer-legal

Public pages for Screenshot Autopilot, the MacOS screenshot-renaming app, served by
GitHub Pages from the `docs/` folder:

- Marketing: https://taylorjpatterson.github.io/screenshotautopilot-legal/
- Privacy Policy: https://taylorjpatterson.github.io/screenshotautopilot-legal/privacy.html
- Support: https://taylorjpatterson.github.io/screenshotautopilot-legal/support.html

These are the three URLs App Store Connect asks for.
