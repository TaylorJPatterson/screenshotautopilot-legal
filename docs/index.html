Screenshot Autopilot

Screenshots name themselves.

Screenshot Autopilot is a Mac menu bar app that looks at what is in each screenshot and gives the file a real name — Safari article about sourdough baking 2026-08-11.png instead of Screenshot 2026-08-11 at 12.03.49 PM.png. It cleans up the screenshots already piling up in your folders, not just the next one you take, and everything happens on your Mac: no account, no upload, no subscription.

Because the name now says what the screenshot contains, the screenshot is searchable: type a word that was in it into Spotlight or the Finder search box and the file comes up.
